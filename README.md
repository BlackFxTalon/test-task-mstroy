# test-task-mstroy

Тестовое задание MStroy Frontend v3.2: класс `TreeStore` (TypeScript) и Vue 3 компонент
с таблицей AgGrid (дерево, Enterprise) для его визуализации.

## План

1. Каркас проекта: Vite, Vue 3, TypeScript, Vitest, ESLint, Prettier.
2. `TreeStore` с индексами `Map` для быстрых операций.
3. Unit-тесты и тесты производительности `TreeStore`.
4. Компонент таблицы на `ag-grid-vue3`: дерево, колонки «№ п/п», «Категория», «Наименование».
5. Загрузка `items.json` через `fetch` с задержкой 2 с и индикатором загрузки.
6. Тесты компонента, финальное оформление README.
